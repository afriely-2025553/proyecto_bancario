# Sistema bancario académico (Banco Ceiba)
Proyecto integrador del curso Taller 2. Sistema para gestionar clientes, cuentas y operaciones bancarias simuladas (depósitos, retiros y transferencias).
Todos los datos del sistema son ficticios y se usan solo con fines educativos.

## Estructura
| Carpeta | Contenido |
| --- | --- |
| `database/` | Scripts de MySQL: usuario de la aplicación, tablas y datos de prueba |
| `backend/` | API REST con Node.js, TypeScript y Express |
| `frontend/` | Aplicación web con Angular |
## Tecnologías
Angular, Node.js con TypeScript, Express, MySQL 8 y pnpm.
